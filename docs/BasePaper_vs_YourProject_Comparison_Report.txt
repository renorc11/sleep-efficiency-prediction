3) Comparison Summary
======================================================================
Methodology
- Base paper: single dominant XGBoost classifier for multi-disorder risk.
- Your project: multi-model framework (RF, XGB, Hybrid) + explainability + recommendation pipeline.

Interpretability
- Base paper: SHAP feature importance and questionnaire simplification.
- Your project: SHAP + humanized local insights + recommendation engine in app UI.

Deployment
- Base paper: web questionnaire deployment.
- Your project: full-stack web + Android app, device usage integration, optional user sleep-time hint.

Performance Perspective
- Base paper reports very high AUROC across disorders (0.897 to 0.949).
- Your project reports high ROC-AUC too for the derived Good/Poor task (0.971 to 0.987), with strong regression fit (best R^2 ~0.933).
- Because tasks differ, compare as: "both achieve high-discrimination ML outcomes in their own problem settings."
